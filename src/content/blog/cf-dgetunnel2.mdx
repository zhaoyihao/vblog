<Collapse title="代理IP、优选IP、优选订阅含义与区别">

- ✅ **PROXYIP（代理 IP）**——“换个身份上网”
  - 定义：用于代理转发流量的中转 IP，客户端会先连接这个 IP，再由它帮你访问目标网站，从而隐藏真实 IP。
  - 核心：代理转发、隐藏真实 IP、突破网络限制
  - 常见用途：
    - Cloudflare Workers
    - VLESS / Trojan / Xray
    - sing-box
    - CF Tunnel
    - 自建代理中转
  - 特点：不一定是最快 IP，只要能稳定代理即可，可以手动指定。
  - 一句话：PROXYIP = 网络 “马甲”，实际负责“流量中转”的代理入口 IP。

---
---

- ✅ **优选 IP**——“从大量 IP 中筛选出的高速线路”
  - 定义：通过测速、延迟、丢包率、稳定性等方式，从大量可用 IP 中筛选出的高质量 IP。
  - 核心：低延迟、高速度、高稳定性
  - 常见筛选条件：延迟低、丢包少、带宽高、不易被封、解锁能力强
  - 常见用途：
    - Cloudflare 优选
    - CDN 加速
    - 代理节点加速
    - Warp / Workers / VLESS
  - 特点：本质只是 IP 地址，通常需要手动填写或生成配置
  - 一句话：优选 IP = 代理 IP 中经过测速筛选后的“高速 VIP 通道”。

---
---

- ✅ **优选订阅**——“自动集成优选 IP 的订阅配置”
  - 定义：将优选 IP、节点配置、规则等内容整合成可直接导入客户端的订阅链接。
  - 核心：自动化、免配置、自动更新
  - 通常包含：自动优选 IP、节点配置、分流规则、自动测速排序、自动更新
  - 支持客户端：
    - Clash
    - Shadowrocket
    - Surge
    - sing-box
    - v2rayN
  - 特点：普通用户直接导入即可使用，不需要手动测速，更适合长期稳定使用
  - 一句话：优选订阅 = 优选 IP + 节点配置 + 自动更新 的完整代理方案。

</Collapse>

### PROXYIP 订阅默认是自动获取，会优选最好用的给你用，但是如果你需要指定某个国家的IP地址，那么你可以把下面指定国家的反代订阅填入下图的红框里，点击保存，然后去代理软件(V2rayN)，更新订阅即可。

```
proxyip.cmliussss.net
```
