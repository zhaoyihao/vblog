甲骨文云（Oracle Cloud Infrastructure）的 Always Free 套餐，是目前市面上唯一能提供长期免费云服务器的平台。注册过程出了名的难，有人一次过，有人折腾大半年。这篇教程整合了注册前准备、填表流程、避坑细节和注册后的注意事项，帮你把能提前做对的事都做对。

## 一、Oracle 免费资源到底有哪些？
Oracle Always Free 提供的不只是一台免费服务器，而是一组可以自由分配的免费资源，所有免费资源都必须在主区域内创建（主区域尽量选欧美。容易申请到实例）。
![oraclefree.png](https://mycc.mcck.ccwu.cc/file/7fd130537b454cf8.png)
免费计算实例

| 类型 | 规格 | 说明 |
| :--- | :--- | :--- |
| AMD Micro | 最多2台，每台1个OCPU + 1GB内存的小服务器 | 适合轻量应用 |
| ARM Ampere A1 | 每月1500 OCPU小时 + 9000 GB小时 | 折合每个月持续运行`2个 OCPU + 12GB内存` |

![oracle](https://mycc.mcck.ccwu.cc/file/41fc03afcb8943dc.png)

> 💬重点提示：目前可创建3台服务器，两台 Always Free VM (AMD)实例，另外一台是2个OCPU +12G内存的大服务器(ARM)。2026年6月15日起，Oracle将 Always Free 的 ARM Ampere A1 配额从 4 OCPU / 24GB 内存减半至 2 OCPU / 12GB 内存。

1. CPU部分：1,500 ÷ 720小时 ≈ 2.08 OCPU。所以，你刚好可以用 2个OCPU 的配置， 24小时不间断地跑满整个月。

2. 内存部分：9,000 ÷ 720小时 = 12.5 GB。所以，你刚好可以用 12 GB内存 的配置，24小时不间断地跑满整个月。

<Success>所以 Always Free 的 ARM 计算资源等效于 2个 OCPU 和 12GB 内存，因此可以创建一台 2核12G 的实例，或者拆分成两台 1核6G 的实例，这样可以拆成总共4台小一点的服务器，但这几台免费服务器的200G存储空间是共享的，每个实例的最小启动卷大小是47GB，所以可以拆成至少50G存储空间的4个小服务器。</Success>

![Oracle](https://mycc.mcck.ccwu.cc/file/d95c02c1291a41f3.png)

3. 引导卷和块存储卷的总大小即存储资源：200GB Block Volume
这是最容易被误解的地方。200GB Block Volume 不是每台服务器送200GB，而是你的整个账户共享一个200GB的存储池。你创建服务器时，都是从200G这个池子里分配启动盘空间，每台服务器存储空间最低需要分配50G。

![oracle](https://mycc.mcck.ccwu.cc/file/1324a63e8490413d.png)

<Collapse title="终止实例时如何正确删除引导卷">

1. 在终止实例时最好勾选 “永久删除附加的引导卷” (Permanently delete the attached boot volume)，重新释放出引导卷空间，不要选择“保留引导卷”。

---

2. 如果在终止实例时选择了“保留引导卷”，这些卷不会自动消失，而是会继续占用你的免费存储额度。要释放空间，你需要手动删除这些不再使用的引导卷，其方法是通过控制台手动删除：

-	导航到引导卷：登录OCI控制台，点击左上角的汉堡菜单，依次进入 “存储” (Storage) -> “块存储” (Block Storage) -> “引导卷” (Boot Volumes)。

- 查找并删除：在引导卷列表中，找到状态为 “已分离” (Detached) 的卷（这表示它没有挂载到任何实例上）。

- 点击该卷右侧的操作菜单（三个点），选择 “终止” (Terminate)。在弹出的确认窗口中确认删除。请注意，此操作不可逆转，数据将永久丢失。

---

> 💬重点提示：在甲骨文云里，“已终止”等同于“已删除”。这个卷已经不在运行了，相关的计算资源已经被释放。“已终止”卷，它们不会占用你的免费额度，可以放心。只有状态为“可用”（Available）或“已挂载”（Attached）的卷才会被计入使用量。


</Collapse>

4. 引导卷性能 (VPU)，在免费套餐内，可以直接拉到最大（120），不会产生额外费用，Oracle的免费额度限制的是“总容量”（200GB），而不是“性能”（VPU），只要你的所有引导卷和块存储卷的总大小不超过200GB，就不会产生费用。选择更高的VPU性能，不会消耗你200GB的存储额度

5. 其他免费资源
- 对象存储：20GB

- 公网IP：1个预留公网IP

- 出站流量：10TB/月

- Autonomous Database：2个，每个1 OCPU + 20GB存储

- 证书：5个CA + 150个证书

## 二、注册前的准备工作
Oracle 的风控逻辑核心是：你提供的身份信息包括邮箱、信用卡、手机。
<Info>Oracle 规定每人只能注册一个免费账号——如果邮箱、信用卡、手机号这三项重复使用去注册第二个账号，大概率会被判定为重复注册。 </Info>

1. 网络环境
这是最关键的避坑点之一：注册过程中不要开科学上网或梯子工具。 不要开 VPN、代理，使用真实的家庭宽带或手机热点即可。原因很简单——用代理掩盖真实地理位置，会被风控判定为“刻意遮挡身份信息”，直接拉高被拒概率。同时要避免在不同网络间频繁切换。

2. 邮箱
建议使用不开代理就能正常访问的邮箱，微软 Outlook 是社区推荐最多的选择。国内邮箱（QQ、163），不建议用 Gmail，因为注册过程中需要收验证邮件，用 Gmail 就得开代理才能收，一旦在网络环境间切换，很容易触发风控。不要使用最近已注册过甲骨文云的邮箱再去注册。

3. 支付方式（最关键的一环）
必须是真实的 Visa 或 Mastercard 信用卡。预付卡、虚拟卡基本会被直接拒绝。添加信用卡验证的地址和名字随便填写，只需保证卡号、到期日、安全码真实，且之前没有用来注册过甲骨文云！

推荐使用招商银行、工商银行、交通银行等主流银行的外币信用卡。注册成功后不要注销这张卡。Oracle 可能在后续进行二次验证扣款（通常为 1.38 新加坡元的预授权验证，验证后会退回），卡失效会导致账号被冻结

4. 手机号
手机号不是最核心的验证项，随便填一个本人真实在用的国内手机号即可，不要用注册过甲骨文云的号码，不要用虚拟号、临时号。

5. 个人信息一致性
姓名、手机号、邮箱、地址、信用卡信息，五项尽量保持同一个人的。用中国身份注册，就用中国手机号、中国地址，不要东拼西凑。最低要保证卡号、到期日、安全码真实，姓名、手机号、地址都可以随便填写，但不能有任何一项之前用于注册过甲骨文云！

## 三、注册流程

不同区域注册链接不同：

日本：<a href="https://www.oracle.com/jp/cloud/free/" target="_blank" rel="noopener noreferrer">https://www.oracle.com/jp/cloud/free/</a>

韩国：<a href="https://www.oracle.com/kr/cloud/free/" target="_blank" rel="noopener noreferrer">https://www.oracle.com/kr/cloud/free/</a>

新加坡：<a href="https://www.oracle.com/asean/cloud/free/" target="_blank" rel="noopener noreferrer">https://www.oracle.com/asean/cloud/free/</a>

1：填写账户信息
打开中国区注册链接，按顺序填写：国家、名字(中文)、姓氏(中文)、邮箱(国内邮箱)，全部按真实信息填写。

![Oracle](https://mycc.mcck.ccwu.cc/file/da3beb3ef16d41d9.png)

---

2：邮箱验证
登录邮箱管理后台，打开验证邮件进行验证。

![Oracle](https://mycc.mcck.ccwu.cc/file/8619091632a54597.png)

---

3：从邮箱验证跳到补全账户信息页面，继续补齐。

备用姓名：输入全名的汉语拼音

![Oracle](https://mycc.mcck.ccwu.cc/file/53b6f8ccd1114e19.png)

---

4：设置 Cloud 账户名称
填写 Cloud Account Name，这是以后登录甲骨文云时需要填写的账户名。每个名称只能申请一次，建议用英文+数字组合，全局唯一。务必记下来，忘记后无法找回。

![Oracle](https://mycc.mcck.ccwu.cc/file/99c9c2a67c294e8b.png)

5：选择 Home Region（主区域）
主区域一旦选定，事后无法更改，慎重选择。 这会直接影响以后抢 ARM 实例的难度(不同区域网络延迟程度以及可用数量、资源紧张程度不一样)。

|  区域  |  延迟（国内）  |  ARM容量  |
| --------- | --------- | ------- |
|  日本东京  |  ~60ms  |  紧张  |
|  韩国首尔  |  ~80ms  |  紧张  |
|  新加坡  |  ~70ms |  紧张  |
|  美国凤凰城 (Phonenix) |  ~180ms |  较充足  |
|  美国阿什本(Ashburn)  |  ~200ms  |  较充足  |

选择策略：

- 追求低延迟：选东京、首尔或新加坡，这几个离中国大陆近一些的国家，但东京和首尔这两个国家太过热门，Oracle也提醒很难申请的到，可选另外两个大版或新加坡。

- 追求 ARM 实例更容易抢到：选美区凤凰城或阿什本(凤凰城靠近西海岸，离中国更近网络延时更小，阿什本在美国东部，离中国更远，虽距离上确有差异，但网络质量上完全不用担心)，可选域更多，延迟更高，容量更充足。如果要用 Claude、ChatGPT 等有地域限制的应用那就直接选美区。

---

6：填写地址信息
地址信息、城市、省份、邮政编码全部按真实信息填写，与信用卡账单地址保持一致。地址行1可以用中文，也可以全部使用汉语拼音，但使用汉语拼音记得用空格分开，不要写成没有任何间隔的一整串字符。

![Oracle](https://mycc.mcck.ccwu.cc/file/f3845dcc31e5495d.png)

7：填写手机号码
填写国内手机号码时，确保该号码之前未注册过甲骨文云，然后点继续。

---

8：信用卡验证
点击【添加付款验证方式】→【Credit Card】，输入卡号、到期日期和安全码。完成后你的信用卡会被预扣款约 1.38 新加坡元（预授权验证，稍后原路退回）。

![oracle](https://mycc.mcck.ccwu.cc/file/0be9b73fc836482d.png)

![Oracle](https://mycc.mcck.ccwu.cc/file/e603d578756f4597.png)

---

9：确认协议并提交
勾选服务协议，点击【开始我的免费试用】。

![Oracle](https://mycc.mcck.ccwu.cc/file/61bc166b153c4af5.png)

提交后大概率立刻看到结果，看到下面的界面代表注册成功：

![Oracle](https://mycc.mcck.ccwu.cc/file/b9aca9cfd6c94de7.png)

同时你也会收到一封注册成功的邮件：

如果看到的是 A、B、C 错误提示：代表这次失败了，不要灰心，间隔一段时间再试，不要频繁提交，否则会被标记。

## 四、登录验证

1. 登录网址：<a href="https://www.oracle.com/cn/cloud/free/" target="_blank" rel="noopener noreferrer">https://www.oracle.com/cn/cloud/free/</a>

2. 输入 Cloud 账户名（注册时填写的 Cloud Account Name）

![Oracle](https://mycc.mcck.ccwu.cc/file/66b0a3866fa74db6.png)

3. 输入登录用户名（注册邮箱）和密码

![Oracle](https://mycc.mcck.ccwu.cc/file/7f0c70f483c44052.png)

启用安全验证：是甲骨文云的安全验证机制，是第一次登录的必选项目，无法跳过

![Oracle](https://mycc.mcck.ccwu.cc/file/7029c5f5e06a411c.png)

点击【启用安全验证】之后，在选择方法界面中，选择【移动应用程序】，然后勾选【脱机模式或使用其他验证程序应用程序】。

![Oracle](https://mycc.mcck.ccwu.cc/file/922836f76bd74267.png)

下载好身份验证器 Oracle Mobile Authenticator 后，打开手机上安装的 Authenticator身份验证器，点击加号，然后用手机扫描Oracle提供的二维码，将甲骨文登录账户添加到验证器中。

![Oracle](https://mycc.mcck.ccwu.cc/file/42c52e3d44034c2c.png)

然后将验证器中生成的验证码填写到 `3.输入应用程序生成的验证码` 输入框中，并点击点【验证】按钮。

![Oracle](https://mycc.mcck.ccwu.cc/file/39e09af2c8924bd0.png)

点【验证】按钮后，会看到 已成功注册 的提示，这代表完成了验证器和Oracle账号的绑定。点击【完成】按钮，系统会自动登录，并跳转到甲骨文云后台中。以后甲骨文登录验证时，就输入这个验证器中产生的码进行验证。

![Oracle](https://mycc.mcck.ccwu.cc/file/9cd64b73405149ee.png)

![Oracle](https://mycc.mcck.ccwu.cc/file/8c83fd7430384a6c.png)

到这里，甲骨文云注册及登录步骤就全部完成了，现在你已经拥有了自己的甲骨文云账户。也不可避免的开启了自己的折腾之旅。

<Warning> 
除了甲骨文默认的身份验证器，也可用谷歌、微软或其他兼容的验证器，这些验证器同样都可以完成安全验证。但对于国内用户来说，想要在安卓市场和苹果市场都能搜索到可用的身份验证器，就只有选择微软的 `Microsoft Authenticator` !

</Warning>
